"""
==================== merge_retrieved_info 合并召回信息 完整业务流程 ====================
输入DataAgentState三大召回数据：
    1. retrieved_columns: list[ColumnInfoQdrant]   Qdrant召回字段元数据
    2. retrieved_values: list[ValueInfoEs]         ES召回字段取值样例
    3. retrieved_metrics: list[MetricInfoQdrant]   Qdrant召回指标元数据
依赖资源：meta_mysql_repository（MySQL元数据持久层）

# 阶段1：全局字段字典去重容器初始化
1. 创建 retrieved_columns_map: dict[字段id, ColumnInfoQdrant]
   作用：统一存放所有需要用到的字段，全局去重，方便后续查表/取值/指标关联字段补全

# 阶段2：补全指标关联缺失字段
遍历每一个召回指标 retrieved_metric:
    取出指标关联字段id列表 relevant_columns
    遍历每个字段id：
        if 字段id 不在 retrieved_columns_map：
            1. MySQL根据id查完整字段 ColumnInfoMySQL
            2. 转换为 ColumnInfoQdrant
            3. 存入 retrieved_columns_map

# 阶段3：根据ES字段取值补充字段样例examples，补全缺失字段
遍历每一个召回字段取值 retrieved_value：
    取出当前取值所属字段id column_id、取值文本column_value
    if 字段id 不在 retrieved_columns_map：
        1. MySQL查字段元数据 → 转ColumnInfoQdrant存入map
    if 当前取值不在该字段examples列表：
        把column_value追加进字段examples（扩充样例给LLM参考）

# 阶段4：按table_id分组，构建【表-字段】映射关系
初始化 table_to_column_map: dict[表id, 字段列表list[ColumnInfoQdrant]]
遍历 retrieved_columns_map 中所有字段：
    取出字段归属table_id
    不存在该table_id则新建空列表
    将当前字段追加到对应表的字段列表

# 阶段5：补全每张表的主键、外键字段（元数据完整性）
遍历每一张table_id：
    MySQL查询该表所有主外键字段 key_columns: list[ColumnInfoMySQL]
    提取当前表已存在的所有字段id集合 column_ids
    遍历每个主外键：
        if 主键/外键id不在当前表已有字段：
            转换为ColumnInfoQdrant，追加到该表字段列表

# 阶段6：循环每张表，转换为Agent流转轻量状态 TableInfoState
遍历 table_to_column_map 中(table_id, 全量表字段)：
    1. 批量转换 ColumnInfoQdrant → ColumnInfoState
       处理逻辑：舍弃id/table_id，examples/alias列表保留原始list（后续会拼接字符串给LLM）
    2. MySQL根据table_id查表基础信息 TableInfoMySQL
    3. 封装 TableInfoState（name/role/description+转换后的字段列表）
    4. 加入最终输出集合 table_infos

# 阶段7：指标结构简单转换 MetricInfoQdrant → MetricInfoState
遍历所有召回指标 retrieved_metric：
    直接解包字典生成 MetricInfoState，存入 metric_infos

# 输出返回给DataAgentState
return {
    "table_infos": list[TableInfoState],    整合完成的表+字段结构化信息
    "metric_infos": list[MetricInfoState]   精简后的指标流转实体
}
====================================================================================
"""
